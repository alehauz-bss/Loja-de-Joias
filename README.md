# 💎 Hub Joias — Operação & Inteligência de Marketing

Bem-vindo ao repositório central da **Loja de Joias** (operação de Dropshipping Nacional com catálogo integrado Hub Joias).

Este projeto reúne a estrutura do catálogo de produtos, planejamento de campanhas, plano operacional e o ecossistema de **Agentes Autônomos de Marketing**.

---

## 📂 Arquitetura do Repositório

