# Criador e Gerador de Skills

## Como criar novas habilidades para o projeto
Esta Meta-Skill orienta a criação, atualização e organização de novas habilidades no projeto. O objetivo é garantir que qualquer nova habilidade criada seja útil, direta ao ponto, fácil de entender e escrita em linguagem 100% humana — sem bordões corporativos ou robóticos de inteligência artificial.

---

## 5 Passos para Criar uma Nova Skill

1. **Entender a Necessidade**: Qual problema prático essa nova habilidade vai resolver? (Ex: pós-venda, garantia, controle de estoque, embalagens).
2. **Definir o Nome da Pasta**: Use minúsculas separadas por hífen, de forma clara (ex: `pos-venda-e-trocas`).
3. **Escrever o `SKILL.md`**: Preencha com metadados `name` e `description` no topo e use linguagem direta e humana.
4. **Incluir Exemplos Reais**: Coloque mensagens reais, modelos de conversa ou tabelas simples de decisão.
5. **Cadastrar no README.md**: Adicione a nova habilidade na tabela principal do arquivo `.agents/skills/README.md`.

---

## Estrutura Modelo para Novos Arquivos `SKILL.md`

Ao criar uma nova habilidade, use a seguinte estrutura limpa e sem complicação:

```markdown
---
name: nome-da-skill
description: Descrição simples e direta do que a skill faz.
---

# Título da Habilidade

## Para que serve esta habilidade
[Explique em 2 ou 3 frases o objetivo prático].

---

## Diretrizes e Passo a Passo
[Orientações claras sobre o que fazer e como fazer].

---

## Exemplos Práticos
[Mensagens reais, modelos de texto ou tabelas de orientação].

---

## Checklist de Qualidade
- [ ] Item 1 verificado
- [ ] Item 2 concluído
```

---

## Regras de Ouro de Linguagem (Zero Cara de IA)

Toda nova habilidade deve passar pelo filtro de humanização:

| O que NÃO usar (Sintético de IA) | Como escrever de verdade |
| :--- | :--- |
| "Alavancar vendas", "Potencializar resultados" | "Vender mais", "Aumentar faturamento" |
| "Abordagem holística", "Ecossistema sustentável" | "Visão geral", "Trabalho integrado da loja" |
| "É fundamental ressaltar que...", "Ademais..." | Vá direto ao ponto sem enrolação |
| Listas cheias de emojis genéricos em cada palavra | Use marcadores limpos e emojis sutis |
| Texto parecendo contrato ou manual burocrático | Fale como uma fundadora ou gerente experiente de loja |
